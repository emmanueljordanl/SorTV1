# Política de decisión

Lógica ejecutable: tres predicciones válidas, top1 > 0.80, margen > 0.15 y dos votos de consenso. El destino lleno o desconocido pide revisión. RECHAZO por incertidumbre y OTRO conocido comparten depósito 3 y conservan motivos diferentes. El dominio físico debe confirmarse mediante supervisión.
